# Network-Enumeration-Lab

## Project Overview
This project demonstrates the network enumeration phase of a cybersecurity assessment using Kali Linux and Nmap. The lab covers host discovery, port scanning, service version detection and service enumeration to identify and document network assets and exposed services within controlled virtual environment. 

## Objectives
- Discover active hosts on the network
- Perform TCP port scanning
- Identify running services and versions
- Enumerate FTP and SMTP services
- Document findings and their security implications

## Lab Environment
-Kali Linux (Scanning Machine)
-Metasploitable 2 (Target Machine)
-pfsense(to provide internet connection as we are using Internal network)
-Oracle VirtualBox
-Internal Network

## Tools used
-nmap
-Telnet
-Kali Linux
-Virtual box

## Methodology
This project follows the early phases of the Certified Ethical Hacker (CEH) methodology, focusing on network scanning and enumeration. The objective is to identify active hosts, discover open ports, detect running services and enumerate network services within a controlled laboratory.
