# TCP SYN STEALTH Scan

## Objective
Identify open TCP ports on the target host (192.168.1.114) using nmap's TCP SYN Stealth Scan Technique.

## Command used
nmap -sS -v 192.168.1.114

-sS: Nmap sends SYN packets to the target ports and analyses the response without completing the TCP three-way handshake

# Results
The scan identified 23 open TCP ports on the target host

## Analysis
The SYN scan successfully identified the same open ports found during the TCP Connect scan

The main difference is that SYN scan does not complete the TCP handshake, making it faster and less detectable compared to a TCP Connect Scan.

The target host appears to expose multiple services, including web services, remote access services, file sharing services and database services.

# Conclusion
The TCP SYN Stealth Scan successfully enumerated open TCP ports on the 192.168.1.114. This information can be used for further service enumeration and vulnerability assessment.
